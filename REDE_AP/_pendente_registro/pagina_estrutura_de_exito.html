Estrutura de Êxito

Etapa EX. O campo guarda só uma parcela de cada memória — os graus 0 a 4 da esfera, 25 dos 225 números, a forma do todo em resolução baixa — e usa essa parcela para guiar os neurônios. A AlphaFi afinada, a partir de uma pista com 40% dos neurônios trocados, comparada só consigo mesma. Relevos estáticos: arraste para girar, pince para aproximar. Dados reais, semente 130, memória 0.
