## Argumento Central

A hipótese do projeto, em uma proposição:

> **φ é a aproximação matemática mais próxima do padrão organizador  
> que precede a estrutura — em sistemas biológicos, em sistemas de  
> informação, e em qualquer sistema que cresce preservando coerência interna.**

As constantes que estruturam o projeto:

```python
PHI   = 1.6180339887   # razão áurea — atrator, expansão
ALPHA = 1/137.035999   # constante de estrutura fina — âncora individual
```
